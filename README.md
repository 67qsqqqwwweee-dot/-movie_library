# Личная кинотека (Movie Library)

Рукосуева София Александровна
## Описание

Это простое GUI-приложение для хранения информации о фильмах. Пользователи могут добавлять фильмы, просматривать список, фильтровать по жанру и году выпуска. Данные сохраняются в JSON-файл и загружаются при запуске программы.

## Использование

1. Запустите файл `main.py`.
2. Введите название, жанр, год выпуска и рейтинг фильма.
3. Нажмите «Добавить фильм» для добавления в библиотеку.
4. Для фильтрации используйте поля фильтрации и кнопку «Применить фильтр».
5. Все данные сохраняются автоматически при добавлении и загружаются при запуске.


## Пример теста

- Введите фильм: Название: "Интерстеллар", Жанр: "Научная фантастика", Год: 2014, Рейтинг: 8.5
- Нажмите «Добавить фильм».
- Используйте фильтр по жанру «фантастика» или по году «2014» и посмотрите результаты.
